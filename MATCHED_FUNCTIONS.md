# Matched functions (masterred92 fork)

Index of Golden Sun (USA) functions matched by Kenny (masterred92) for
[Coaltergeist/goldensun-decomp](https://github.com/Coaltergeist/goldensun-decomp). Every entry builds byte-identical
(`make clean && make compare`: ROM and all 96 overlays OK).

**Oct 25, 2026: consolidated.** Per the maintainer's request on #91, the 59 per-batch PRs
(#32-#59, #61-#91) were closed and resubmitted as three area PRs, each rebased on upstream
`main` (2e5c504c) with overlaps resolved:

- [#93](https://github.com/Coaltergeist/goldensun-decomp/pull/93) map overlays: `kenny/consolidated-maps`
- [#94](https://github.com/Coaltergeist/goldensun-decomp/pull/94) field, battle, UI, RPG and menus: `kenny/consolidated-field-ui`
- [#92](https://github.com/Coaltergeist/goldensun-decomp/pull/92) common2 (libgcc soft-float) and its per-file flag: `kenny/consolidated-common`

Each branch passes `make clean && make -j1 compare` on its own and merged with the other two.
They contain C and header source, the Makefile tweaks described in the PRs, and three `.s`
data stubs that only reference ROM offsets (`.incrom`/`.incbin` of the extracted overlay).
No ROM bytes, assets or original assembly are committed.

Upstream rules applied: no inline asm emitting data; `.equ` only for pooled literals in the
existing `.Lconst_<hex>` style; no register pins, `do {} while (0)` fillers, or return-type tricks.
Fifteen functions that only matched through one of those were put back to `INCLUDE_ASM` (see below).
